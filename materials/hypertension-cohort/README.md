# Hypertension Cohort: Claude Code starter project

This is the practice project for Part 2: Analyzing research data with Claude Code. It holds data from a fictional two-arm trial of **intensive vs. standard blood-pressure control** at 3 sites, with BP measured at baseline and at 3, 6, and 12 months. You'll use Claude Code to clean the data, make a Table 1, fit the primary model from the analysis plan, and write a Quarto report.

> **All data here is synthetic.** Every value was generated by a computer. No real patients are involved. Don't add real patient data to this project.

The raw data has some **data quality problems on purpose**. Finding and fixing them is part of the exercise.

## Open the project in Positron

1. Unzip the folder somewhere you can find it, such as `Documents/`.
2. In Positron, choose **File → Open Folder** and select the `hypertension-cohort` folder.
3. You should see `CLAUDE.md`, `data/`, `docs/`, and the other folders in the Explorer.

## Start Claude Code

Use either of these. Both work on the folder Positron (or VS Code) has open.

- **Extension panel (main way in class):** open any file, then click the Spark icon in the editor toolbar (top right). Or click **✻ Claude Code** in the status bar (bottom right), which works even with no file open.
- **Terminal (requires the standalone CLI):** open the **Terminal** tab and type `claude`. The extension doesn't put `claude` on your PATH, so this works only if you installed the standalone Claude Code CLI. A few things in class only work here.

Claude reads `CLAUDE.md` at the start of every session. That file holds the project rules, such as "data/raw/ is read-only."

A good first prompt:

```
Read the SAP and the data dictionary. Propose a step-by-step plan to
clean the raw data and run the primary analysis. Don't write code yet.
```

## Use Python instead of R

The project uses R by default. To use Python:

1. Delete `CLAUDE.md` (the R version).
2. Rename `CLAUDE.python.md` to `CLAUDE.md`.
3. Start a new Claude Code session. Claude will put scripts in a `python/` folder.

You'll need Python with pandas, numpy, statsmodels, matplotlib, and pytest. To render the Python report you also need Jupyter.

## What's in the folder

```
hypertension-cohort/
├── CLAUDE.md              # standing instructions for Claude (R version)
├── CLAUDE.python.md       # the same instructions for Python
├── README.md              # this file
├── data/
│   ├── raw/               # read-only source data (synthetic)
│   │   ├── class_cohort.csv
│   │   └── redcap/        # three per-site "REDCap exports" to combine
│   ├── restricted/        # fictional stand-in for data Claude must never read
│   └── data_dictionary.csv
├── docs/
│   └── SAP.md             # statistical analysis plan
├── legacy/                # old SAS and Stata code to explain or translate
├── R/                     # numbered analysis scripts (01_clean.R, ...)
├── output/                # cleaned data, tables, and figures
└── reports/               # Quarto report (report.qmd)
```

## Check the work yourself

Claude writes the code. You check it. Run each script in Positron's Console, open the cleaned data in the **Data Explorer**, and make sure the numbers make sense before you trust them.
