# Part 1 class kits

These files are for **Part 1: Getting started with Claude**. In class you put one kit's files into a Claude Project, then use the Project to practice prompting and checking Claude's answers. Pick **one** kit.

| Kit | Who it's for | Project name | Files to upload |
|---|---|---|---|
| **Kit A: Article Explainer** (default) | Anyone who reads or explains research articles: students, educators, researchers, clinicians, library staff | Article Explainer | `kit-a/explainer-style-guide.md` and `kit-a/hickey-2025-telehealth-htn.md` |
| **Kit B: Committee Assistant** | Administrative staff who support committees and meetings | Committee Assistant | `kit-b/committee-pack-synthetic.md` |

## How to use a kit

1. Download your kit (the zip file, or the single files from the class page).
2. In the Claude app, create a Project and paste the Project instructions from the class page: [site URL]/part1.html#build-project
3. Upload the files listed above for your kit. Don't upload this README.
4. Follow the steps on the class page.

The files are plain text (`.md`). You can open them in any text editor or web browser, and you can search them with Ctrl+F (Cmd+F on a Mac). If your computer saves a file as `.md.txt`, see the troubleshooting notes on the setup page: [site URL]/index.html#setup-part1

## What's in each file

- **`kit-a/explainer-style-guide.md`**: a short, made-up style guide for plain-language explainers. It sets audiences, the parts every explainer has, and language rules you'll check Claude against.
- **`kit-a/hickey-2025-telehealth-htn.md`**: a text copy of a real, open-access research article: Hickey MD et al. Community health worker–facilitated telehealth for moderate–severe hypertension care in Kenya and Uganda: A randomized controlled trial. *PLoS Med.* 2025;22(6):e1004632. [doi:10.1371/journal.pmed.1004632](https://doi.org/10.1371/journal.pmed.1004632). It is reformatted as text so search works reliably. The wording is the authors'; nothing was corrected. The file's header has the full citation and license.
- **`kit-b/committee-pack-synthetic.md`**: a made-up committee charter and one month of rough meeting notes. People are named by role only.
