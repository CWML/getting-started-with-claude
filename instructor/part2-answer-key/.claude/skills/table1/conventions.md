# Table conventions
- Continuous: mean (SD) if roughly symmetric, otherwise median [IQR].
  State which in a footnote.
- Categorical: n (%), percentages to 1 decimal place.
- Column headers show group N, e.g. "Intensive (N = 250)". Include an Overall column.
- Units in variable labels, from the dictionary's units column, e.g. "Baseline systolic BP, mmHg".
- Footnote defines every abbreviation.
