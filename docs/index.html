Claude at the School of Medicine

Training materials from the Yale Cushing/Whitney Medical Library

These pages are the class materials for two in-person classes from the Cushing/Whitney Medical Library. Getting started with Claude shows anyone at the School of Medicine how to use the Claude app well and safely. Analyzing research data with Claude Code teaches researchers to clean and analyze study data. The second class builds on the first, but you can take either one on its own. Instructors teach from these pages, so you can follow along in class or work through them on your own.

What you’ll learn

Getting started with Claude

  1. Identify the right tool and settings for your data.
  2. Apply prompting patterns to a real task.
  3. Evaluate Claude’s answers and citations before you use them.
  4. Create a Project you can reuse for your own work.

Analyzing research data with Claude Code

  1. Configure a Claude Code project that protects raw and restricted data.
  2. Implement a plan-first workflow to clean and analyze study data.
  3. Evaluate AI-generated code and results against the analysis plan.
  4. Build a reusable command, skill, or hook for a research data task.

Data use

WarningNo patient data, ever
  • In class, use only the class files and public information. Never use patient data or other sensitive information in either class.
  • A HIPAA-supported version of Claude is available by request: [request link]. Being HIPAA-supported doesn’t approve your project, every feature, or every data set.
  • Before you use Claude with real work data, follow [Yale data classification / policy link]. Questions go to [HSIT / HIPAA Privacy Office contact].

Both classes use only fictional (synthetic) files or public, openly licensed material. The article in Getting started with Claude is an open-access paper (Hickey et al., PLoS Medicine 2025, CC BY). The hypertension trial in Analyzing research data with Claude Code is made up.

In class you’ll build a Claude Project: a workspace with your own instructions and files. Pick one kit. Both use the same steps.

Kit Who it’s for What’s in it Download

NoteIndividual files, and the Windows .md.txt problem

Individual files (if you’d rather not use a zip):

  • Kit A: explainer-style-guide.md · hickey-2025-telehealth-htn.md
  • Kit B: committee-pack-synthetic.md
  • About the kits: README.md

To save a single file, right-click the link and choose Save link as (or Download linked file). If you just click it, the file may open as text in your browser.

Windows: your file may save as name.md.txt. That’s fine; Claude can read it. To fix the name, open File Explorer, choose View > Show > File name extensions, and delete .txt from the end.

Setup for Analyzing research data with Claude Code

About 30 minutes. Do the steps in order. You need a Yale Claude account whose seat includes Claude Code: [how to check / who to ask].

1. Positron and R (or Python)

Positron is a free data science editor from Posit, the makers of RStudio. It works with R and Python and includes Quarto. VS Code (version 1.94 or later) works too, but class is taught in Positron.

  • R (recommended)
  • Python

Install R from https://cloud.r-project.org. Positron finds it automatically. Then, in Positron’s R Console, run:

install.packages(c("tidyverse", "here", "gtsummary", "gt", "broom", "janitor", "testthat"))

Install Python 3.10 or later from https://www.python.org/downloads/. Then, in Positron’s Terminal, run:

python3 -m pip install pandas numpy statsmodels matplotlib jupyter pytest

In class, you’ll swap the project’s CLAUDE.md for the Python version (the project’s README.md explains how).

2. git (required)

In class, git saves checkpoints of your work so you can undo mistakes.

git config --global user.name "Your Name"
git config --global user.email "you@yale.edu"
