# Analyzing Research Data with Claude Code

## Title

Analyzing Research Data with Claude Code

## Modality & location

In person: SHM L 111

## Duration

90 minutes

## Brief description of training

A hands-on class for faculty, postdocs, students, research coordinators, analysts, and clinicians who can read a little R. Using Claude Code in Positron (or VS Code), you'll analyze real, public CDC survey data (NHANES, August 2021–August 2023) and try to reproduce a published CDC estimate of how many U.S. adults have high blood pressure. You'll set up a project that protects raw and restricted data, have Claude plan before it writes any code, let it write and run the R scripts, and check each step yourself. Along the way you'll decide which tasks to hand to Claude and which decisions stay yours. This class doesn't replace learning R or statistics; it shows where a coding agent speeds up good analysis and where your expertise must stay in control. Two instructors teach it from the class web page. Bring a laptop with about 30 minutes of setup done before class, and a Claude account whose seat includes Claude Code. The data are public and de-identified, not patient data.

## Learning objectives

By the end of this class, you'll be able to:

1. **Configure** a Claude Code project that protects raw and restricted data.
2. **Implement** a plan-first workflow to clean and analyze study data.
3. **Distinguish** tasks to delegate to Claude from decisions you keep.
4. **Evaluate** AI-generated code and results against the analysis plan.
