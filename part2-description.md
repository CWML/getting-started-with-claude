# Analyzing Research Data with Claude Code

## Title

Analyzing Research Data with Claude Code

## Modality & location

In person: SHM L 111

## Duration

90 minutes

## Brief description of training

A hands-on class for faculty, postdocs, students, research coordinators, analysts, and clinicians who can read a little R or Python. Using Claude Code in Positron or VS Code, you'll take a synthetic clinical trial from raw CSV files to a Quarto report: plan first, let Claude write and run the code, check each step yourself, and finish by building a reusable tool for your own research data.  Bring a laptop with about 30 minutes of setup done before class, and a Claude account whose seat includes Claude Code. No real patient data is used.

## Learning objectives

By the end of this class, you'll be able to:

1. **Configure** a Claude Code project that protects raw and restricted data.
2. **Implement** a plan-first workflow to clean and analyze study data.
3. **Evaluate** AI-generated code and results against the analysis plan.
4. **Build** a reusable command, skill, or hook for a research data task.
